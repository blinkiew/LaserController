# LaserController
 Use lasers to play games and controll your pc.

## Zones
Zone is area on your camera used to detect ONE laser inside it.
They contain markers - four points that define area location.
You can also set pixels threshold to channel brightness, or give a custon X
brightness function.

## Joystick
You can assign a joystick class to zone to turn your laser into stick or button.
Combine it with emulators (like Bluestacks), or PC games and play them just with laser.

## Debug Windows
Debug Window is powerful tool for debugging or monitoring your laser position and settings.
Just create one Debug Window class and pass a sequence of zone classes as first parameter.

See code examples to learn about debugging methods
